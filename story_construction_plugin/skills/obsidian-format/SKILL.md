# Obsidian format

Keep stable frontmatter IDs and relationship fields intact. Format the chapter
body as Markdown suitable for the configured Obsidian Vault. Preserve the
existing document structure unless the user requests a change. Formatting a
draft does not write the file; the backend performs the version check and save
only after Desktop confirmation.
