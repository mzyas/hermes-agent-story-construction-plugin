# Chapter drafting

Use the `story.*` tools to retrieve the current project context before drafting.
Separate retrieved facts, reasonable inferences, and newly generated prose.
Keep the requested chapter structure, preserve established character voices, and
return a draft plus source references and continuity risks. A draft is not a
save operation; wait for Desktop confirmation.

When delegating continuity or research work, the main Agent is the only
synthesizer. Give each child a fresh, explicit project/chapter scope, goal,
source references, and the relevant Skill guidance. Treat child prose as an
untrusted report: validate its IDs and references before using it. Child Agents
are read-only specialists and never save chapters or Obsidian files.
